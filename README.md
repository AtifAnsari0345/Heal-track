# Heal Track

Heal Track is a real-world healthcare web app that integrates hospital appointments, home doctor visits, online medicine ordering, emergency services, and more — built using HTML, CSS, JS, Node.js, Express, and MongoDB.

## Features
- Secure Login/Signup
- Profile Management
- Doctor Appointment Booking
- Medicine Shop
- Home Doctor Visit
- Emergency Contact System
- Feedback & Recent Activities

## Technologies
- Frontend: HTML, CSS, JS
- Backend: Node.js, Express.js
- Database: MongoDB
