# HealTrack

HealTrack is a full-stack healthcare platform that allows users to book appointments, order medicines, manage profiles, and interact with doctors. Built as a real-world hospital management web app.

---

## 🚀 Features
- Patient–Doctor portal with separate access levels
- Appointment scheduling & real-time availability
- Online medicine ordering
- User profiles with medical history
- REST API–based backend
- Secure authentication module

---

## 🛠️ Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Node.js (Express)  
**Database:** MongoDB  
**Other:** REST APIs, Session Management
